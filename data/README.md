# Data

All data in this repository are generated by the code in this repository. No external or
third-party dataset is used or redistributed. Provenance for every file:
[`docs/DATA_PROVENANCE.md`](../docs/DATA_PROVENANCE.md).

`data/reference/` holds the verified reference solutions of the book's running examples
(Appendix D) and their verification records:

| Directory | Running example | Generated by |
|---|---|---|
| `exA/` | A: heat equation (exact solution; FTCS, Crank-Nicolson and P1 finite-element verification); also the 2D Poisson finite-difference check of §8.9 | `code/reference_problems/exA_heat.py`, `code/chapter06/fem_1d.py`, `code/chapter08/poisson2d_fd_convergence.py` |
| `exB/` | B: Lotka-Volterra and pendulum | `code/reference_problems/refs_B_to_G.py exB` |
| `exC/` | C: viscous Burgers, `nu = 0.01/pi` | `refs_B_to_G.py exC` |
| `exE/` | E: Robertson kinetics | `refs_B_to_G.py exE` |
| `exF/` | F: SEIR model with time-varying transmission | `refs_B_to_G.py exF` |
| `exG/` | G: Lorenz-63 and Lorenz-96 | `refs_B_to_G.py exG` |

Example D (Darcy flow) is verified and generated by the Chapter 9 scripts; its dataset is
`results/chapter09/darcy_dataset.npz`.

Each `verification.json` records a convergence or tolerance study. For the ODE examples this is a
self-consistency check (the change between successive tolerances), which indicates, but does not
prove, the accuracy of the finest solution; for Examples A and C an independent exact or
semi-analytic solution is available; see Appendix C of the book for when a numerical solution is
treated as a reference.
