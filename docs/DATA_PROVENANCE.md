# Data provenance

Every dataset in this repository is synthetic: it is generated by a script in this repository from
stated equations, parameters and random seeds. No external or third-party data are used, so no
third-party license applies, and all data are distributed under the repository's license (see
[`LICENSING_REVIEW.md`](LICENSING_REVIEW.md)).

The trained model states under `results/chapter09/sweep_*/state_n200_seed*.pt` and
`results/chapter09/legacy_first_order_solver/deeponet_state_n200.pt` are derived artifacts (PyTorch
`state_dict` files, about 0.1 MB each). They can be regenerated with `deeponet.py`, deterministically
on a fixed platform, and are stored so that Chapters 12 and 14 can be reproduced without retraining.
`.pt` files are loaded with `torch.load`, which unpickles data. Load only files from a source you
trust, such as this repository.
