# Licensing review

The repository is released under the MIT License ([`LICENSE`](../LICENSE)). This note records the
review on which that choice rests.

## Code

- Every Python file was written for the book by its author. No file carries a third-party license
  header or copyright notice, and none states that it was copied or adapted from another project.
- The methods (physics-informed networks, Deep Ritz, DeepONet, Fourier neural operators, SINDy,
  Kansa collocation, Kalman filtering and so on) are implemented from their published mathematical
  descriptions, which the book cites. No third-party implementation such as DeepXDE, neuraloperator
  or PySINDy is included or vendored.
- The dependencies (NumPy, SciPy, SymPy, Matplotlib, PyTorch, pytest, and optionally JAX and Optax)
  are installed separately and are not redistributed. Their licenses (BSD-style, Apache-2.0, MIT)
  are compatible with MIT-licensed code that uses them.

## Data, results and figures

- All data and results are generated by this repository's code (see
  [`DATA_PROVENANCE.md`](DATA_PROVENANCE.md)). No third-party dataset is included.
- The figures are the author's own and also appear in the book, which carries the CC BY 4.0
  license. Distributing them here under MIT is compatible with that.

## Scope

The MIT License covers the whole repository: the code and the "associated documentation files",
which here include the documentation, stored results and figures. The book itself is licensed
separately under CC BY 4.0. Nothing found in this review prevents release under MIT.
